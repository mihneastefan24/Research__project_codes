Spacecraft Guidance, Navigation & Astrodynamics

This directory contains MATLAB projects developed during MSc coursework in Space Engineering, focusing on spacecraft guidance, navigation, orbital mechanics, and astrodynamics.

Topics

Orbital propagation

Orbit determination and state estimation

Kalman filtering

Relative spacecraft dynamics

Circular Restricted Three-Body Problem (CR3BP)

Halo orbit computation

Low-thrust trajectory design

Interplanetary transfers

Station keeping

Projects

SGAN_Propagator.m

Numerical spacecraft orbit propagation using different dynamical models.

SGAN_Kalman_Filter.m

Implementation of state-estimation techniques for spacecraft navigation using simulated measurements and covariance propagation.

SGAN_Halo_Orbit.m

Computation and analysis of halo orbits within the Circular Restricted Three-Body Problem.

SGAN_Earth_Venus_Transfer.m

Numerical analysis of an Earth–Venus interplanetary transfer, including trajectory propagation and transfer performance.

SGAN_Station_keeping.m

Simulation and analysis of orbital station-keeping manoeuvres.

SGAN_Direction.m

Supporting calculations for spacecraft trajectory and orbital dynamics analysis.
