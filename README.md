# Research Project Codes
A consolidated collection of computational research software, numerical solvers, and simulation models developed for the MSc in Space Engineering at Politecnico di Milano.

---

## 📌 Core Modules

* **Asteroid Dynamics:** Granular aggregate generation, network topology, and particle reintroduction models in C++ and MATLAB.
* **Hypersonic CFD:** Custom numerical PDE solvers in Python, Gmsh geometry/mesh generation, and SU2 flow field simulations.
* **Numerical Methods:** MATLAB and Simulink (`.slx`) models for dynamic system analysis, electrical circuits, and numerical modeling.
* **SGAN:** Space Dynamics & Guidance Navigation suite covering orbital propagation, Halo orbits, low-thrust optimization, and state estimation.
